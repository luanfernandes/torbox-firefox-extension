# Security policy

## Supported versions

Security fixes currently target the latest release.

## Reporting a vulnerability

Do not put API keys, passwords, private source URLs, generated links, TorBox responses, or exploit details in a public issue.

Use GitHub's private vulnerability-reporting link when it is enabled:

https://github.com/luanfernandes/torbox-firefox-extension/security/advisories/new

If that link is unavailable, open a public issue containing no sensitive details and ask the maintainer to provide a private contact route.

If a report may have exposed a TorBox API key, revoke or replace that key immediately. Remove affected Hoster passwords and generated links from any shared material.
