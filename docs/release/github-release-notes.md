This is an unsigned AMO upload candidate and source package.

Release Firefox and Zen builds require Mozilla signing. Normal users should wait for the public Mozilla Add-ons listing or use a Mozilla-signed XPI. The `firefox-amo-upload.zip` file will not remain installed in a normal Firefox or Zen release build.

The source archive and checksums are included for review and reproducibility. See [CHANGELOG.md](https://github.com/luanfernandes/torbox-firefox-extension/blob/main/CHANGELOG.md) for the version summary.
