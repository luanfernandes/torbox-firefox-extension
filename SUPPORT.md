# Support

Search existing [GitHub issues](https://github.com/luanfernandes/torbox-firefox-extension/issues) before filing a new one.

A useful bug report includes:

- Firefox or Zen version and operating system;
- extension version;
- the affected Hoster name;
- the visible extension error and the steps that produced it;
- whether the problem occurs in a clean browser profile.

Remove API keys, passwords, embedded URL credentials, Mega fragments, generated links, account identifiers, and private browsing details before posting. Follow [SECURITY.md](SECURITY.md) if the report cannot be made safe for a public issue.

TorBox account, billing, quota, and server-side download failures belong with TorBox support. This repository supports only the unofficial browser extension.
